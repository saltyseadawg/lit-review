# Notes
### Research question

- What difficulties are ppl having when learning Canto?
- Why do people want to learn Canto?
### Findings
- ppl perceive Canto as really hard to learn
	- diglossia
	- pronunciation
	- tones
- want more help from teachers with speaking practice, colloquial speech, daily speech
- want more interesting materials
- want to learn Canto because in HK, communication, work, daily life
	- priority is work, being able to participate in local culture also important
- everyone liked being able to practice w/ native speakers outside of classroom regardless of time spent studying
- 90% of ppl thought teaching materials sucked 
	- lack of quality
	- lack of quantitity
	- ppl interested in computer aided tools, multimedia

### Discussion
- linguistic issues
- psychological issues
- sociocultural
	- ppl in HK speak to non-Chinese ppl in English 
	- when native canto speakers do talk to expats, they don't have normal convos, teaching and correcting mistakes
	- no support, external validation
	- always be asking WHY foreigners want to learn Canto
	- not interested in helping foreigners/expats learn
	- locals also don't understand why ppl want to learn canto
		- English prestige
	- >90% of ppl in HK use Canto as primary language 
- suggestions
	- tones aren't actually that important for being understood
		- usually can get it from context
		- learners overestimate the importance
		- but is important for having ood pronunciation
	- difficult initials and finals, 
	- dipthongs/tripthongs
	- contrasts that are hard
- Lee(2018b) has suggestions for CAPT tool design
- if it is hard for learners to find opportunities to practice, classrooms need to create safe spaces for learners to practice these skills and build confidence
